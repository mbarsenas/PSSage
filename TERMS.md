# PSSage Terms of Use — Draft

_Last updated: August 15, 2026_

PSSage provides automated PowerShell parsing, static analysis, diagnostics, and test scaffolding. Results may be incomplete or incorrect and should be reviewed before use.

PSSage does not guarantee that a script is secure, production-ready, or appropriate for a particular environment. Users remain responsible for testing code, protecting credentials, maintaining backups, and following applicable organizational policies.

Version 0.1 does not intentionally execute user-submitted PowerShell source as a user script or make changes to a user's computer or external systems.

Before public submission, replace this draft with finalized terms identifying the verified developer or business entity and support contact.
